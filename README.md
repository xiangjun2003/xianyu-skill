# 闲鱼 Skill 🐟

**从“我想吃、我想看、我想买”，找到具体能用、价格合适、交易条件清楚的闲鱼购买方案。**

你说一句“我想吃奥尔良烤翅”，Agent 会先问是否方便登录闲鱼。同意后立即打开登录入口、推进登录，确认成功后再补齐需求、搜索闲鱼、货比三家，核对具体门店、商品规格、实际支出和售后。

菜品名、品牌、优惠券、代下单、搜索关键词，都可以由 Agent 接着找。你只需要说清楚想要什么。

## 先确认登录，再开始查

Agent 会先问：“你现在方便登录闲鱼吗？方便的话，我先打开登录入口。”

- 方便：立即进入登录流程，需要时请你扫码或在手机确认；核验成功后继续搜索。
- 已有有效且已授权的登录态，或本次对话已经同意登录：直接复用或继续，不重复询问、不强制重登。
- 暂不方便：先用可读的公开信息或你提供的材料，说明查询范围和限制。

登录在 Agent 实际使用的浏览器或连接器环境中完成，无需把密码、验证码或 Cookie 发进聊天。

## 三个例子

### 🍗 我想吃奥尔良烤翅

> 我想吃奥尔良烤翅。

确认登录选择后，Agent 会补问城市或附近商圈、自取还是外送；已有的信息直接沿用。然后从菜品出发找不同品牌和购买方式，比较单点、餐券及代下单。

**要落实到：去哪家店、能买几块、什么时候可用、一共付多少。** 不会把香辣鸡翅、烤翅根或冷冻半成品直接当成同一餐品，也不会把“门店待核实”的低价当成最终推荐。

### 🍔 我想点个 KFC

> 想点个 KFC，帮我看看怎么买更划算。

已想好餐品，就按对应规格比较；还没决定，就结合人数、预算和口味找合适的组合，再比较闲鱼上的代下单或卡券。

**比的是这顿实际要花的钱。** 核对所选餐厅、单点或套餐的数量、服务费、门店补差、取餐方式，以及无货或下单失败怎么办。

### 🎬 我想买电影票

> 今晚想看电影，帮我找划算一点的票。

Agent 会补齐城市、时间和人数；有片名或影院偏好就沿用，没有就结合当前排片找选项，再比较对应电影票或代订报价。

**要落实到：哪家影院、哪天哪场、几个人、是否含服务费和特殊厅补差。** “全国通兑”“低价起”需要继续核对到本次场次；比价时不会擅自锁座、出票或付款。

以上是使用情境，商品、价格、库存、门店与场次均在每次运行时查询。

## 它会怎么帮你选

| 关注什么 | Agent 做什么 |
| --- | --- |
| 买到想要的 | 匹配餐品、口味、份量、型号或场次，说明替代选项的差别 |
| 确实用得上 | 核对具体门店与地址、使用时段、交付方式及适用条件 |
| 比出真实价格 | 查看目标规格的价格与库存，算整单支出，再比较单位价 |
| 找到更有保障的 | 查看平台内交易、交付办法、失败退款和相关卖家记录，区分页面事实与卖家承诺 |
| 把问题问清楚 | 缺位置等信息时主动补问；确需联系卖家时，取得授权后围绕本次条件询价 |

默认先看一批相关商品，尽量比较至少三位独立卖家。重复链接按卖家去重；只有一家满足条件时就如实说明。

搜索卡片的最低价可能对应别的商品，低价规格也可能已经售罄。推荐以**满足本次需求的具体规格、可用门店和完整总价**为依据；还有核心缺口就继续查证，或说明实际阻塞。

## 最后会得到什么

一个首选，加上少量有意义的备选，并附上：

- 实际商品链接、卖家和所选规格。
- 本次能得到的数量、整单支出及单位价。
- 具体门店或影院、地址、可用时间和交付方式。
- 门店或场次适用的依据、失败处理及售后条款。
- 选择理由、仍存在的限制、查询时间和比较范围。

只在已核实的候选中判断哪个更划算。评价、销量和认证是参考依据，不能代替本次商品的适用条件或履约确认。

## 怎么用

1. [下载仓库](https://github.com/xiangjun2003/xianyu-skill/archive/refs/heads/main.zip)并解压，将 **`xianyu` 文件夹**导入支持 `SKILL.md` 或本地技能的 Agent 宿主。若宿主要求 ZIP，仅压缩这个文件夹即可。
2. 在宿主中启用浏览器操作，或连接已有的闲鱼工具。
3. 直接说生活需求，例如“我想吃奥尔良烤翅”；按需选择“闲鱼 skill”。Agent 会先确认能否登录，你同意后就直接开始登录流程，再继续查询。

技能负责理解需求、检索策略、核查与比较；实时商品由宿主的浏览器或闲鱼工具读取。豆包工作等聊天平台的导入入口、工具权限和登录状态，以当前客户端为准；本仓库未完成各宿主的端到端兼容测试。

默认执行搜索、核查和推荐。联系卖家、议价、下单、付款等依照你的实际授权分别执行；已经授权的范围不会反复询问。登录凭证留在当前受控环境，无需发进聊天。

## 技能内容

```text
xianyu/
├── SKILL.md                  # 需求理解、搜索、核查、比价与推荐
├── agents/openai.yaml        # 技能名称与默认入口
└── references/
    ├── access.md             # 使用宿主浏览器或已有连接器
    ├── categories.md         # 餐饮、电影票及其他消费的核查要点
    └── comparison.md         # 费用口径与保障证据
```

也支持卡券、生活服务、实物和二手商品，以及比较你提供的闲鱼链接。它们沿用同一条原则：先核对是否满足需求，再比较真实支出和履约依据。
